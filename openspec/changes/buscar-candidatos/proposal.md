# Buscar candidatos en el tablero de LTI

El PR #5 ya implementa movimiento y rollback. El ejercicio nuevo permite localizar candidatos por nombre en el mismo tablero, sin nuevas peticiones ni cambios backend. La vista filtrada debe mantener la identidad de cada candidatura al arrastrar.

Incrementos: búsqueda y conteo; vacío y recuperación accesible; convivencia con el arrastre existente. Fuera de alcance: búsqueda global en servidor, paginación, filtros por score, persistencia de consulta y cambios de UI library.
